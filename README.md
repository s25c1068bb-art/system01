# system01

材料からおすすめ料理と推定カロリーを表示するコマンドです。

入力された材料の組み合わせから、おすすめの料理と推定カロリーを表示します。

## 必要なソフトウェア

- Python 3

## テスト環境

- OS: Ubuntu 24.04 LTS
- Python: 3系

## ダウンロード

以下のコマンドでリポジトリをダウンロードします。

```bash
git clone https://github.com/s25c1068bb-art/system01.git
cd system01
```

## 使用方法

標準入力から材料を入力して実行します。

```bash
echo "卵 ご飯" | python3 system01/system01.py
```

## 実行例

### 卵とご飯を入力した場合

```text
おすすめ料理: チャーハン
推定カロリー: 550 kcal
```

### 卵とパンを入力した場合

```text
おすすめ料理: フレンチトースト
推定カロリー: 400 kcal
```

### パスタとベーコンを入力した場合

```text
おすすめ料理: カルボナーラ
推定カロリー: 700 kcal
```

### じゃがいもと玉ねぎを入力した場合

```text
おすすめ料理: ポテトスープ
推定カロリー: 250 kcal
```

### 鶏肉と玉ねぎを入力した場合

```text
おすすめ料理: 親子丼
推定カロリー: 600 kcal
```

### 該当する料理がない場合

```text
おすすめ料理: 料理なし
推定カロリー: 0 kcal
```

※ カロリーは推定値です。
